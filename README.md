# GateKeeper - Advanced API Gateway Project

## Services Overview
- **gateway** → Spring Cloud Gateway (routes, rate limiting, auth)
- **auth** → Authentication microservice (JWT + user management)
- **svc-java** → Example backend (Spring Boot)
- **svc-go** → Example backend (Go)
- **infra** → Docker Compose setup (Redis, monitoring tools)
- **docs** → Architecture diagrams, API specs, etc.

### Tech Stack
Java 17, Go 1.20+, Spring Boot 3, Redis, Docker, Prometheus, Grafana, ELK.- infra (docker-compose, k8s manifests, observability)
